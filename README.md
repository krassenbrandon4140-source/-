# AlphaPulse AI — 글로벌 150+ 종목 AI 모의투자 플랫폼

초기 자금 **₩10,000,000 (천만 원)**으로 실제 글로벌 주식·암호화폐 시장 데이터(Yahoo Finance)를 매일 AI가 자동 분석·모의 매매하고, 수익률 그래프와 상세한 **매수/매도 사유**를 제공하는 웹 플랫폼입니다.

## 실행 방법

```bash
python run.py
```

실행 후 브라우저에서 `http://127.0.0.1:8000`으로 접속합니다.

## 주요 기능

- **150개 글로벌 관심 자산 + SpaceX 프록시(`DXYZ`)**: 미국 빅테크, 반도체(TSMC 포함), AI/SW, 양자컴퓨팅, 헬스케어/바이오, 한국(삼성전자·SK하이닉스·알테오젠 등 13종목), 중국/아시아, 유럽, 우주/위성, 3D프린팅/로보틱스 등 17개 섹터 전 종목 및 실시간 환율(KRW) 자동 환산.
- **멀티팩터 AI 퀀트 엔진**: 이동평균 정배열/골든·데드크로스, RSI(14), MACD, 볼린저밴드, 상대 거래량(RVOL), ATR 기반 동적 목표가/손절가 계산.
- **투명한 매수·매도 사유 리포트**: 모든 거래에 대해 핵심 시그널 배지, AI 확신도, 한국어 상세 판단 근거, 리스크 노트를 기록 (선택사항: Gemini API 키 입력 시 LLM 데일리 브리핑 강화).
- **고급 인터랙티브 차트 (ECharts)**:
  - AI 포트폴리오 누적 수익률 vs S&P 500 vs 코스피 비교 곡선
  - 섹터별 자산 배분 도넛 차트 & 일별 수익률 바 차트
  - 종목별 6개월 일봉 캔들스틱 + 이동평균선(5/20/60) + RSI(14) + **AI 매수/매도 체결 마커**
- **운용 모드 & 자동 스케줄러**: 누적 복리 운용 / 매일 1,000만 원 리셋 모드 전환, 평일 지정 시각 자동 모의매매 스케줄러, 30거래일 실제 시장 리플레이 시뮬레이션 지원.
